# Sunshine configuration notes

Sunshine creates its full config on first run at:
```
~/.config/sunshine/sunshine.conf
```

Recommended defaults for unstable networks:
- Codec: H.264
- Resolution: 1280x720
- FPS: 30
- Bitrate: 2-12 Mbps (adaptive)
- Low-latency preset enabled

You can set these in the Sunshine Web UI.
