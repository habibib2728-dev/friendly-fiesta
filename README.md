# Sniper Motorsports Website

Luxury performance shop website for Sniper Motorsports with an animated hero,
services, gallery placeholders, and a dedicated Affirm financing page.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view.

## Deployment (Vercel)

1. Push this repo to GitHub.
2. Import the repo in Vercel.
3. Use the default Next.js settings.
